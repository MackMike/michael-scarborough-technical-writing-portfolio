# Apache OpenOffice Technical Editing

This folder contains supporting materials for my Apache OpenOffice technical editing portfolio sample.

## Project Summary
This project highlights my technical editing work on Apache OpenOffice user documentation, including the Calc 4.1, Draw 4.1, and Impress 4.1 user guides. The sample demonstrates editorial improvements in clarity, consistency, structure, readability, and usability across end-user documentation.

## Contents
- `openoffice-technical-editing-overview.pdf` — project overview, including audience, goals, constraints, tools, and results
- `openoffice-editing-highlights.pdf` — concise before-and-after examples of representative edits
- `openoffice-detailed-editing-examples.pdf` — fuller before-and-after examples with additional explanation
- supporting materials as applicable
