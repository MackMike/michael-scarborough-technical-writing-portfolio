# Migrate User Administrative Tool Documentation

## Overview
This project documents an AppleScript-based administrative tool used to restore ownership and group permissions on a migrated user's home folder after a Mac has been reimaged.

The sample was prepared as a portfolio piece to demonstrate administrator-focused technical writing, internal tool documentation, improved interface text, and maintainable code comments.

## Audience
- Platform administrators
- Desktop support technicians
- macOS administrators

## Project Components
This repository includes:

- a polished administrator README
- a revised AppleScript with improved comments and user dialogs
- a historical note explaining the relationship between the original internal version and the portfolio edition

## What This Sample Demonstrates
- Technical writing for administrator audiences
- Internal tool documentation
- Task-based instruction writing
- Troubleshooting documentation
- Revision of interface text and prompts
- Maintainable code commenting
- Translation of a technical workflow into clear, structured documentation

- AppleScript

## Portfolio Summary
I originally created this tool to support an enterprise macOS migration workflow. For this portfolio edition, I revised the supporting documentation, comments, and dialogs to make the tool clearer, more maintainable, and more appropriate for an administrative audience.

This sample reflects my ability to document technical workflows, improve usability through better language, and present internal tooling in a professional, user-focused format.
