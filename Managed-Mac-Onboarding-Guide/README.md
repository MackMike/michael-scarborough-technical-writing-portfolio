# Managed Mac Onboarding Guide

Task-based quick-start guide for end users receiving a company-managed Mac. Covers setup, authentication, connecting to the secure company network via Zscaler, accessing Microsoft 365 and Office apps, using Jamf Self Service, and basic troubleshooting.
