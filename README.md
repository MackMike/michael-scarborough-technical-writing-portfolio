# Michael Scarborough Technical Writing Portfolio

For a broader overview, visit my [portfolio site](https://mackmike.github.io/technical-writing-portfolio-site/) or [GitHub profile](https://github.com/MackMike).

I am a Technical Writer and Editor with a background in macOS systems engineering, endpoint management, and enterprise IT. I create clear, structured documentation that helps end users and technical teams complete tasks, troubleshoot issues, and follow processes more consistently.

This repository includes selected writing and editing samples in Markdown, XML, and GitHub-based formats, with examples of onboarding guides, troubleshooting articles, administrator documentation, technical editing, and introductory DITA-based structured authoring.

## Featured Samples

### [Managed macOS Onboarding Guide](./Managed-Mac-Onboarding-Guide/)
Task-based end-user documentation for setting up a company-managed macOS device. Demonstrates clear onboarding guidance, security-related setup, and user-focused troubleshooting that supports a more consistent setup experience.

### [KB Article: Troubleshooting Compliance Failures on Jamf-Managed Macs](./Jamf-Managed-Mac-Compliance-Troubleshooting/)
Knowledge base documentation for diagnosing and remediating compliance failures on Jamf-managed Macs. Demonstrates structured troubleshooting and remediation guidance that helps support teams investigate issues more efficiently and determine next steps.

### [KB Article: Troubleshooting VPN Certificate Issues on Managed macOS Devices](./VPN-Certificate-Managed-Mac-Troubleshooting/)
Knowledge base documentation for resolving certificate-related VPN connection issues on managed macOS devices. Demonstrates support-focused troubleshooting, escalation guidance, and endpoint management awareness for enterprise IT environments.

### [Migrate User Administrative Tool Documentation](./Migrate-User-Administrative-Tool-Documentation/)
Administrator documentation for a tool used to restore ownership and group permissions after macOS reimaging. Demonstrates administrator-focused writing, clearer prompts and warnings, and documentation improvements that support more reliable tool usage.

### [DITA Sample: Managed macOS Onboarding Guide](./DITA-Sample-Managed-Mac-Onboarding-Guide/)
A structured authoring sample that adapts onboarding content into DITA using topic-based organization. Demonstrates foundational DITA skills, structured XML authoring, and modular documentation design.
